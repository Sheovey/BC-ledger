## 五、核心功能口径

- **多账本**：首页卡片切换；数据按 `bookId` 隔离；切换不读文件，只读 storage。
- **分类多选是「标签」不是「拆分」**：一笔 50 元勾 3 个二级分类，金额仍是 50 整，**只归属主分类 `categoryId`**（= `categoryIds[0]`，第一个勾的），其余项不参与任何金额统计。统计一律 `rootOf(tx.categoryId)` 全额计一次。UI 只显示「+N」。**一级只能选一个**：勾到别的根下的子分类时整组替换（`CategoryPicker` 的 `sameRoot` 过滤）。多选时不自动关弹层，收尾用 Sheet footer「完成 · 已选 N 项」。
- **金额键盘**：自绘 4×4 Keypad；`+`/`-` 连算时大号位显示**合计**，小字显示完整算式（`hooks/useAmountInput.ts`）。
- **金额光标**：自绘闪烁竖线。①位置——空内容贴最左，有内容才跟到末尾；②焦点——点进备注/商家必须收起（`amountActive`）。恢复入口有四个：点金额区、按键盘任意键、点「继续输入」、`switchType`。
- **本机自动存档**：每账本 1 个 `.xlsx`（同名覆盖，5 张表）+ 全局 3 份 JSON 快照，落 `USER_DATA_PATH/archive/`。xlsx 是零依赖手写 ZIP + 最小 OOXML（真 Excel 验证过）。调度：写后 idle 4s + xlsx 最小间隔 60s；`onHide` 只写 JSON；启动后 3s 补一次。
- **备份**：「导出完整备份」+「从备份恢复」是唯一能换手机恢复的路径；「发送最新存档到聊天」发 xlsx，**出去了回不来**，界面文案已锁死。

## 六、数据与存储

- **storage 是唯一权威源**，文件是派生产物。`StorageDriver` 用 meta + 流水分片（300 条/片）。
- **备份语义**：必须**写盘前取旧值**（`previousRaw = lastWrittenRaw` → 写盘 → `rotateBackup(previousRaw)`）。写盘后才备份会导致回滚点形同虚设且界面完全正常。备份只留 1 份；超 90 万字符放弃。
- **`DATA_VERSION = 2`**：预设分类改名（金融保险→生活服务、理财收入→补贴收入）必须走 `persist.ts` 的 `applyPresetRenames()`（id + 旧名双命中）。**以后任何预设改名都走这条路**，只改 `seed.ts` 对老数据无效。
- **合规口径**：全仓用户可见文案不得出现 理财/基金/分红/收益/利息/保险/投资/金融/股票/债券/贷款/银行。`cat_finance`/`cat_invest`/图标名 `invest` 是内部标识，保留。
- 首启状态：1 账本 / 5 账户 / **84 预设分类** / 0 流水。

## 八、发布与提审

1. 改版本号两处：`package.json` 的 `version`、`settings/index.tsx` 的 `APP_VERSION`（`npm run upload` 会校验两者一致，不一致 exit 1）。
2. `npm run build:weapp`（3–4 分钟，**不与上传合并**，否则失败分不清哪步）。
3. `node scripts/wxcli.cjs islogin` 预热（`cli upload` 冷启动会卡死）。
4. `npm run upload -- "改动说明"`：备注自动拼 `<版本号> · <日期> · <git 短 sha> · 说明`。**先 commit 再 upload**，否则 sha 指向上一次提交。
5. 后台：管理 → 版本管理 → 开发版本 → 设为体验版 → 扫码真机验证 → 提交审核（审核区单槽位，重新提审会覆盖）→ 过审后**手动点发布**。
6. `git tag -a v<版本> -m "..."` → `git push origin --tags`。

**提审必做（漏了只在真机炸）**：

- 后台「用户隐私保护指引」必须声明 **`MessageFile`（chooseMessageFile）+ `Clipboard`（setClipboardData）**，该栏不能留「未采集用户隐私」。漏声明 → 真机 `errno 112`，开发者工具完全不报。
- 类目 `工具 → 记账`；UGC 选「不含用户生成内容」；`app.json` 不需要 `requiredPrivateInfos`。

**新版本提示机制（1.1.6 起）**：微信在小程序**每次启动（含热启动）**检查更新，包下完需**重启小程序**才生效；切后台 30 分钟内回来是热启动，内存仍是旧代码——这是「发布后手机上仍显示旧版本」的真正原因，不是同步延迟。**不要为了刷版本删小程序**，那会连账本存储一起清。

## 九、工程约定（勿破坏）

1. **按下态**：全仓禁 `:hover`/`:active`，一律 `hoverClass` + `--hover`。`<Text>` 不支持 `hover-class`，用 `<View>`。
2. **选中态**：`accent-soft` 底 + `accent-deep` 字；禁用 `surface-2` 当选中底（与按下态同色）。
3. **字号**：正文不低于 13px、辅助文字不低于 12px；主力档 13 / 13.5 / 14.5 / 15.5。层级要递进（月 > 日 > 行内时间）。
4. **共享组件样式放全局**：被 ≥2 页使用的类不许定义在页面级 scss（`ConfirmDialog` 曾因此在 6 页错位）。
5. **间距别写两遍**：全局 `gap` 与页面级 `margin` 会叠成双倍。`Picker` 是原生组件，参与 flex 的是 `picker` 而非内部 cell。
6. **custom tabBar 两个坑**：①组件树在 `page` 之外，`page{}` 的 CSS 变量继承不到（`var()` 参与的声明整条被丢弃）；②框架渲染在页面之上，页面内 z-index 无效，弹层靠 `useUiStore.sheetDepth` 计数隐藏 tabBar。
7. **列表时间戳**：`TxRow` 的 `stampStyle` —— 流水页不传（日期在日分组标题）/ 统计页 `'date'` / 首页 `'relative'`（今天·昨天·MM-DD，跨年补年份）。
8. **流水分页 30 条/次**，切片必须整天切边，否则日组合计会从全天变半天。
9. **禁止「点了才说没做」的占位入口**：`verify-record` 命中 `暂未接入|未实现|敬请期待|即将上线` 即红。
10. **`dist/` 不入库**：回退后必须重新 build。

### 实现细节备忘（改到这些地方时先看）

- **图标**：Phosphor Bold，52 个 = 48 个取自 `@phosphor-icons/core` 的 `assets/bold/` + back/forward/down/up 四个 chevron 手绘（Phosphor 只有实心三角形，16px 行内箭头会被读成「播放键」）。`npm run icons`（`scripts/gen-icons.cjs`）按脚本内 `MAP` 生成 `icon.scss` + `icon-names.ts`，缺文件即抛错。**Phosphor 文件名除 regular 外都带 `-bold`/`-fill` 后缀**，按 `名.svg` 取会静默读空；viewBox 256×256；data-uri 里 `currentColor` 须换 `#000`。
- **流水分页**：30 条/次 + `useReachBottom`；切片必须**整天切边**（向后补到日边界），否则日组合计会从全天变半天往下跳。副标题与筛选合计永远按**全量**算。
- **月份区间**：`resolveMonthRange` 起点用 `${from}-${pad2(startDay)}` 直接锚定，**不能走 `periodStart`**（起始日 >1 会落到上一账期）。
- **图表明细**：`groupByDimension` 合并长尾时写 `restKeys`，配合 `dimensionKeyOf`/`txsOfGroup` 让聚合与明细共用 key；默认 10 条、+10/次，展开第一组。
- **`useProgressiveList`**：游标重置用**渲染期派生**，不用 `useEffect`（后者先画一帧旧条数，切换闪烁）。
- **流水筛选区布局**：合计卡竖向三段，`.ledger-totals__cell { flex: 1 1 auto }`——**不用 `1 1 0`**，金额位数不同会挤出格；类型 chip 五等分（`1 1 0` + 居中）。
